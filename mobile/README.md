# SET · KIDS — the native app

The student app for Android and iPhone, written in React Native with Expo.
Ruled 8 Oct 2026: a full native rewrite, published to Google Play and the App
Store. It talks to the KIDS website's mobile API (`src/app/api/m/v1` in the
repo root) and shares no screen code with the website.

Read `AGENTS.md` before writing code: Expo changes between SDKs, and this is
SDK 57.

## Run it on a phone

```bash
cd mobile
npm install
npx expo start            # scan the QR code with the Expo Go app
```

The app talks to www.kidskolkata.org unless told otherwise. To use a laptop
running the website (`npm run dev` in the repo root):

```bash
EXPO_PUBLIC_API_URL=http://<laptop-ip>:3000 npx expo start
```

## Checks

```bash
npx tsc --noEmit && npx expo lint && npx expo-doctor
```

`android/` and `ios/` are generated by `npx expo prebuild` and never committed.
